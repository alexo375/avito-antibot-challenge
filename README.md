# Avito AntiBot Challenge

Решение задачи бинарной классификации по потоку событий браузерных кук для выявления ботов в рамках отбора на Авито Data Science Bootcamp


## Основная метрика и результаты

* **Целевая метрика соревнований:** $P@R \ge 0.70$ (Precision при Recall не менее 70%)
* **Константное предсказание (Baseline платформы):** `0.0939`
* **GB CatBoost + Optuna Итерация 1 (93 признака):**
  * Локальный результат на валидации: `0.7778` ($P@R \ge 0.70$)
  * Тестовый результат на платформе: `0.7324`
* **GB CatBoost + Optuna Итерация 2 (104 признака):**
  * Локальный результат на валидации: `0.7808` ($P@R \ge 0.70$)
  * Тестовый результат на платформе: `0.7324`

## О решении

Итоговый набор фич агрегируется по `(cookie_id, window_start_ts, window_end_ts)` и включает **93 признака**:

1. **Сессионная динамика:**
   * Статистики по разницам между событиями: `delta_t_mean`, `delta_t_std`, `delta_t_median`, `delta_t_p10`, `delta_t_p90`
   * Доля быстрых и нулевых задержек (`ratio_subsecond_delta`, `ratio_zero_delta`)
   * Активная длительность сессии и возраст куки (`cookie_age_days`)

2. **Анализ User-Agent и устройств:**
   * Детекция ботов по признакам `has_bot_script_ua`, `has_headless_ua`, `has_platform_ua_mismatch`.
   * Статистика уникальных user-agents на одну куку (`n_unique_uas`, `max_ua_cookie_count`).

3. **Поведенческие метрики:**
   * Разнообразие просматриваемого контента: `ratio_item_diversity`, `ratio_category_diversity`, `ratio_query_diversity`
   * Частота целевых действий: открытие чатов (`n_contact_chat_open`), просмотр контактов (`n_contact_phone_show`), листание фото (`n_photo_swipe`), ввод капчи (`n_captcha_shown`)

4. **Анализ движений курсора:**
   * Перемещение курсора по $L_2$-норме: $\text{dist} = \sqrt{\Delta x^2 + \Delta y^2}$
   * Средняя и максимальная дистанция перемещений (`pointer_dist_mean`, `pointer_dist_max`), стандартные отклонения координат

5. **Последовательности событий:**
   * Извлечение 30 TF-IDF n-gram признаков поверх символьных и пошаговых последовательностей типов событий (`tfidf_ngram_0` ... `tfidf_ngram_29`).

Затем обучается модель градиентного бустинга:
* Временное разбиение по дате начала окна (`window_start_ts >= '2026-04-17'`) на train/val для исключения утечки таргета
* **Модель:** `CatBoostClassifier`
* **Подбор гиперпараметров:** автоматический с помощью `optuna`
* **Финал:** обучение модели с champion-параметрами на 100% размеченных данных перед генерацией сабмита
